Предлагаю рассмотреть концепцию корпоративной AI-платформы мониторинга IT-департамента.

Цель проекта — объединить данные из используемых рабочих систем, автоматизировать регулярную отчётность и создать основу для исторической аналитики и AI-ассистента, способного отвечать на вопросы о состоянии проектов и возникающих рисках.

Предлагаю реализовать проект поэтапно:

1. Провести инвентаризацию источников данных и определить приоритетные показатели.
2. Создать пилот с одной интеграцией, Telegram-ботом и централизованным хранением результатов.
3. Проверить качество данных, полезность отчётов и возможность анализа исторической динамики.
4. По итогам пилота оценить эффект, трудозатраты и целесообразность масштабирования на остальные направления.

На первом этапе предлагается использовать существующие AI-модели с контролируемым доступом к корпоративным данным, без разработки и обучения собственной модели. Вопросы расширения инфраструктуры и прогнозирования предлагается решать по результатам пилота.

Подготовлена предварительная архитектурная концепция. Для перехода к реализации потребуется согласовать источники данных, требования безопасности, ответственных, технические ограничения и критерии успеха.

Предлагаю обсудить концепцию и определить направление для пилотного внедрения.
